# 👟 MARK – Shoe Store

**MARK** is a modern and responsive shoe e-commerce website designed for footwear lovers. It showcases popular international shoe brands and different footwear collections through a clean, stylish and user-friendly interface.

The website is developed using **HTML5 and CSS3 only**, without using any frameworks or JavaScript.

---

## 🌐 About the Project

MARK provides a simple online shopping interface where users can explore different shoe brands, browse footwear collections and view product details.

The website focuses on delivering a modern shopping experience with an attractive layout, responsive design and smooth hover effects.

---

## ✨ Features

- Modern and attractive homepage.
- Responsive navigation bar.
- Premium MARK branding.
- Popular shoe brands section.
- Men's and women's footwear categories.
- Sports shoes and sneaker collections.
- Featured product cards.
- Product prices and discount labels.
- Special offers section.
- Hover animations and transitions.
- Responsive design for desktop, tablet and mobile.
- Modern black, white and orange colour combination.

## 🚀 How to Run the Project

Follow these steps to run the website locally:

1. Clone this repository.

```bash
git clone https://github.com/YOUR-USERNAME/mark-shoe-store.git
```

2. Open the project folder.

```bash
cd mark-shoe-store
```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser.

5. Alternatively, install the Live Server extension in VS Code and click **Open with Live Server**.

## ⚠️ Current Limitations

This project is currently a frontend design demonstration.

- Shopping cart functionality is not implemented.
- Product search is not functional.
- Checkout and payment systems are not implemented.
- User login and registration are not implemented.
- Brand filtering is not implemented.
- Product prices and discounts are sample values.

These features can be added in future versions using JavaScript and backend technologies.
